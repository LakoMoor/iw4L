Pick the “Call of Duty Modern Warfare 2” folder from Steam (it contains main and zone).

What works and what doesn’t yet

  • Done

    IW4PK pack format

    Compressed chunks with the index at the end, so the browser downloads only the map you pick. The pure-Rust reader builds for WebAssembly.

  • Done

    Packer and file tracing

    The engine records which files a map really reads, and only those go into the pack: 11.6 GB becomes 0.7–0.8 GB per map.

  • Done

    The engine builds for WebAssembly

    The whole workspace compiles for the browser: networking, files and time now have browser implementations.

  • In progress

    Running in the browser

    Entry point, a virtual file system over the packs, and rendering through WebGPU.

  • Next

    WebRTC multiplayer

    The host creates an invite, friends paste it and connect directly.

Multiplayer with no server and no open ports

The host stays authoritative: it simulates the match, just like regular IW4L. Other players connect to the host over a WebRTC data channel.

Public STUN servers handle NAT traversal. You need no server, no VPN and no port forwarding, and the invite is shared as a link or a code.

An honest limit. If someone is behind a strict (symmetric) NAT and there is no TURN server, a direct connection may fail. That is a property of WebRTC, not of the engine.

No game files are hosted on this site. Every player uses their own copy of MW2, or gets a private pack from the organizer.
